# PR_Testing

Práctica 2.1 de BolivianWorks: flujo de trabajo con forks, ramas y pull requests.

## Requisitos

- Node.js 20 o superior

## Ejecutar

```bash
npm install
npm run dev
```

## Reglas del proyecto

- Solo se modifican `src/App.vue` y `src/style.css`.
- No se agregan dependencias nuevas.
- Ramas: `feat/<descripcion>`, `bugfix/<descripcion>`, `hotfix/<descripcion>`.
- Commits: `feat: ...`, `fix: ...`, `chore: ...` (descripción en español).
